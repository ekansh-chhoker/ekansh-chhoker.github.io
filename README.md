# Ekansh | Portfolio

Scroll-driven personal portfolio built with plain HTML, CSS and JavaScript, plus Three.js for the GPU point-cloud background.

## Features
- 7,000-point WebGL particle field that morphs between shapes as you scroll
- Pointer field that parts the particles around the cursor
- Word-by-word scroll reveal
- Terminal-style skills section with a typing effect
- 3D tilt project cards
- Dark and light theme, reduced-motion support

## Run locally
Open `index.html` in a browser. No build step needed.

## Deploy
Push to GitHub and enable Pages (Settings > Pages > Deploy from branch > `main` / root).
